1. AWS IAM (Identity and Access Management)

1. Create IAM users, groups, roles, and policies.
2. Create custom IAM policies using the JSON policy editor.
3. Attach AWS-managed and customer-managed policies to IAM users and groups.
4. Configure MFA for IAM users.
5. Reset IAM user console passwords and rotate access keys.
6. Configure IAM users to access AWS through Console, CLI, and SDK.
7. Configure IAM roles and assume roles using AWS STS.
8. Configure cross-account IAM role access between two AWS accounts.
9. Implement least-privilege access using IAM policies.
10. Configure IAM policy conditions based on IP address, region, and MFA.
11. Configure EC2 instance profiles and attach IAM roles to EC2.
12. Troubleshoot IAM AccessDenied errors using policy simulation and CloudTrail.
